# SimCruiser G25

A Lethal Company mod that allows the Company Cruiser to be driven with a Logitech G25 wheel.

## Features

* Adds input bindings for the G25 wheel
* Rewrites the Company Cruiser input system to make driving feel more realistic with the G25

## Setup

This mod was developed with Logitech Gaming Software `5.10.127`, which uses Logitech Profiler for G25 wheel support. It works on Windows 10 and Windows 11.

Newer Logitech software versions may also work, but they have not been tested.

Download the driver from the `Logitech G25 Driver` folder or click [here](https://github.com/LRGuess/SimCruiser-G25/blob/main/LogitechG25Driver/lgs510_x64.exe).

With the driver installed, you can now install the mod. You can:

* Download the `.dll` [here](https://github.com/LRGuess/SimCruiser-G25/blob/main/SimCruiser-G25/bin/Debug/netstandard2.1/SimCruiser-G25.dll)
* Build it yourself
* Install it with [Thunderstore](https://old.thunderstore.io/c/lethal-company/p/BigSaltyBeans/SimCruiser_G25/)

If you choose to download the `.dll`, place it in:

```text
/Lethal Company/BepInEx/plugins
```

## Usage

With the drivers and mod installed, it should now be plug-and-play.

Simply connect the G25 to your computer and launch the game.
