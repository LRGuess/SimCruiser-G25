# SimCruiser G25

A Lethal Company Mod that allows the Company Cruiser to be driven with a logitech G25 wheel.

## Features:  
- Addes input bindings for the G25 wheel
- Rewrites the company cruiser input to make it more realistic with the G25

## Setup

This mod was developped with Logitech Gaming Software `5.10.127` that uses logitech profiler as the G25's wheel support. Works on Win 10/11. I'm not sure if newer versions work, but you can try them out yourself.

Download the driver from the Logitech G25 Driver folder or click [here]()

With the driver installed, it's now time to install the mod. You can download the .dll [here](https://github.com/LRGuess/SimCruiser-G25/blob/main/SimCruiser-G25/bin/Debug/netstandard2.1/SimCruiser-G25.dll), build it yourself or install it with [Thunderstore]()

If you choose to download the .dll place it in `/Lethal Company/BepInEx/plugins`

## Usage

With the drivers and mod installed it should now be plug and play! Simply connect the G25 to your computer and launch the game.
